# VoraToon Personal Extensions

Personal Mihon-compatible extension source and package repository.

## Add repository

Open Mihon and add this repository using the following index URL:

`https://raw.githubusercontent.com/ayounkworks/extensions-source/repo/index.pb`

Repository metadata is available at:

`https://raw.githubusercontent.com/ayounkworks/extensions-source/repo/repo.json`

## Build

The `main` branch contains the extension source code and GitHub Actions build pipeline.
Successful releases are published to the `repo` branch of this repository.

## Source code

- Repository: https://github.com/ayounkworks/extensions-source
- Build workflow: https://github.com/ayounkworks/extensions-source/actions/workflows/build_push.yml

## Notes

This is an independent personal fork based on the Keiyoushi extension framework.
It is not affiliated with Mihon, Tachiyomi, or Keiyoushi.
